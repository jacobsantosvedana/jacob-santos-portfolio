# Jacob Santos Vedana — Portfolio

## Files
- `index.html` — main portfolio page
- `style.css` — design and responsive layout
- `script.js` — mobile navigation + current year
- `assets/profile.png` — profile image

## Run locally
Open `index.html` in a browser, or use VS Code + Live Server.

## Publish
### GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders from this project.
3. Make sure `index.html` is in the repository root.
4. Open the repository's **Settings → Pages**.
5. Choose the publishing source/branch and save.
6. GitHub will provide your live `github.io` URL.

### Netlify
You can also publish by uploading/dragging the project folder to Netlify's deploy area.

## Privacy
The public portfolio intentionally does not include date of birth, religion, gender, or teacher references from the resume. Keep those details in a private resume unless an application specifically requires them.
